# フォーカスタイマー

シンプルなポモドーロ式のフォーカスタイマーです。HTML / CSS / JavaScript のみで動作し、ビルドツールやサーバーは不要です。

## 使い方

`index.html` をブラウザで開くだけで利用できます。

```bash
start index.html
```

## 主な機能

- **集中 / 小休憩 / 大休憩** の3モード切り替え(それぞれ25分・5分・15分)
- リング状のプログレス表示と残り時間のカウントダウン
- セッション完了時のチャイム音とブラウザ通知
- 4回の集中セッションごとに自動で大休憩へ切り替え
- タスクリスト機能(追加・完了チェック・削除、完了ポモドーロ数の記録)
- 完了セッション数とタスクの状態を `localStorage` に保存し、再読み込み後も保持

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリのマークアップ |
| `style.css` | スタイル定義 |
| `script.js` | タイマーとタスク管理のロジック |
